## Описание
Это шаблон для создания новых требований. Используйте его как основу для описания функциональности.

## Функциональные требования
- FR-1: Система должна [действие] для [пользователя/роли] с целью [ценность]

## Нефункциональные требования
- NFR-1: Производительность - время отклика не более X мс при Y запросах в секунду
- NFR-2: Безопасность - данные должны быть защищены согласно стандарту Z

## Критерии приемки (Acceptance Criteria)
1. Given [начальное состояние/контекст], When [пользователь выполняет действие], Then [ожидаемый результат]
2. Given [альтернативный контекст], When [другое действие], Then [альтернативный результат]
