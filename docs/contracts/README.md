# API contracts

Размещайте в этом каталоге версионируемые контракты внешних и межмодульных интерфейсов:

- REST API — OpenAPI (`*.yaml` или `*.json`);
- gRPC — Protobuf (`*.proto`);
- иные форматы — только если они описаны в ADR.

Каждый контракт должен иметь владельца, версию и проверку обратной совместимости. Изменения контракта согласуются до реализации и сопровождаются тестами клиентов и поставщиков.
